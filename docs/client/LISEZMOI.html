LumenStage Previz v0

Moniteur du show Prodigy 12 — écoute le réseau lumière et affiche l'activité DMX en direct. L'application n'émet rien : aucun risque pour le show.

Démarrer (Mac)

  1. Dézippez l'archive où vous voulez (Bureau, Documents…).
  2. Clic droit sur Start-LumenStage.command → Ouvrir → Ouvrir (nécessaire la première fois seulement).
  3. Si macOS demande d'autoriser node à accepter les connexions réseau entrantes : Autoriser.
  4. Le navigateur s'ouvre sur http://localhost:4480 — c'est le Monitor.

Message « Node.js 20 ou plus récent est requis » ? Installez la version LTS depuis nodejs.org (2 minutes), puis relancez le fichier.

Démarrer (Windows)

Double-clic sur Start-LumenStage.bat. Même logique.

Tester sans la console

Double-cliquez en plus sur Start-FakeShow.command (ou .bat) : il simule la console et envoie un show de test. Les 4 univers s'animent dans le Monitor.

Avec la vraie console

  1. Branchez l'ordinateur au réseau lumière (Ethernet) et réglez l'IP selon les indications de la régie.
  2. Dès que la console envoie de l'Art-Net sur les univers 1–4 (les Tambora), le Monitor s'anime tout seul.

En cas de problème

  • NO SIGNAL : vérifiez le câble réseau, l'IP, et que la console émet bien sur les univers 1–4.
  • La page ne s'ouvre pas : allez manuellement sur http://localhost:4480.
  • « UDP 6454 unavailable » : une autre application Art-Net tourne sur cette machine — fermez-la et relancez.

Arrêter

Fermez la fenêtre Terminal (ou Ctrl+C dedans).
