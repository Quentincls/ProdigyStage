LumenStage

A live 3D copy of the Prodigy 12 light show, on your screen.

Safe by design: this app only listens to the lighting network. It never sends anything to the lights. You cannot break the show with it — not even by accident.

Part 1 — Install and open it (5 minutes, at home)

You only do this once. You need a Mac and an internet browser.

  1. Unzip the file you received. Put the LumenStage folder anywhere (Desktop is fine). a folder containing a few files, including Start-LumenStage.command.
  2. Right-click (not double-click!) on Start-LumenStage.command, choose Open, then Open again in the warning popup. macOS asks this the first time only — afterwards a normal double-click works. a black Terminal window opens with a few lines of text. Leave it open — it IS the app. Closing it stops everything.
  3. If your Mac asks “Do you want the application node to accept incoming network connections?” → click Allow.
  4. Wait 2 seconds. your browser opens by itself on a dark screen: a 3D room with the message “Waiting for the console”. That's normal — nothing is connected yet.

Instead you got a message saying “Node.js 20 or newer is required”? That's a small free program the app needs. Go to nodejs.org, click the big green LTS download button, install it like any app (2 minutes, once), then go back to step 2.

Part 2 — See it working, without the console (2 minutes, at home)

The folder includes a fake lighting console, so you can see the app alive right away.

  1. Keep the app from Part 1 running.
  2. Right-click on Start-FakeShow.command → Open → Open (first time only). a second Terminal window with a line of numbers updating every second.
  3. Go back to your browser. the two light walls in the 3D room are now animating — rainbows, waves, chases — and the top bar says “Console connected” with a green dot. A time counter runs at the bottom left.
  4. Play around: drag the mouse to turn around the room, scroll to zoom, press keys 1, 2, 3 for ready-made camera angles.
  5. Done playing? Close both Terminal windows. That's how you quit.

Part 3 — At the venue, with the real show

Do this together with the lighting operator. Allow 15 minutes the first time.

  1. Connect the Mac to the lighting network with an Ethernet cable (ask the operator which socket/switch).
  2. Ask the operator what IP address to give the Mac, and set it in System Settings → Network → your Ethernet connection.
  3. Start the app (Start-LumenStage.command, like in Part 1). Show the operator the orange note below.
  4. Ask the console to play anything on the light walls (the Tambora bars). the 3D walls light up and move exactly like the real room, and the top bar turns green: “Console connected”. If the console sends its timecode, the counter bottom-left runs in sync with the show.
  5. The most useful thing you can do: record a full run of the show. Click the gear ⚙ (top right) → Runs → ● Record a run before the show starts, and stop it at the end. This creates a file in the LumenStage/data/recordings folder — send us that file: it lets us build and test everything else on the real show, without the console.
  6. If the colors on screen don't match the room (say, red on stage but blue on screen): film 10 seconds showing both the room and the screen, and send us the video. It's a 5-minute remote fix on our side.

Show this to the lighting operator: the console must actually send Art-Net for universes 1–4 towards this computer. If the console only sends unicast to the DMX nodes, this Mac will see nothing. Either enable broadcast for universes 1–4, or add this Mac's IP as an extra unicast destination. Two-minute change, fully reversible, the rig keeps receiving normally. This app listens only — it never replies or transmits.

Good to know

  • Watch / Edit (top left): Watch is just looking. Edit lets you draw scenes on the timeline and try effects — they appear on screen only, never on the real lights.
  • To quit: close the Terminal window(s). Nothing keeps running in the background.
  • Nothing you click anywhere in this app can affect the real show.
